# 仕様書

> 本ファイルはプロジェクト（展示作品ホームページ）の仕様をまとめたものです。
> 仕様に変更があれば本ファイルを更新してください。

---

## 1. プロジェクト概要

| 項目 | 内容 |
| --- | --- |
| プロジェクト名 | 展示作品ホームページ |
| 種別 | 展示作品ホームページ（静的サイト） |
| 目的 | 展覧会の開催概要と展示作品を紹介する Web サイトを公開する |
| 実装言語 | Python 3.10 以上（標準ライブラリのみ） |
| 公開形態 | `dist/` に生成された HTML/CSS/JS を任意の静的ホスティング（GitHub Pages 等）に配置 |

## 2. 機能仕様

### 2.1 主要機能

| ID | 機能名 | 概要 | 状態 |
| --- | --- | --- | --- |
| F-001 | トップページ | ヒーロー（展覧会名・会期）、展覧会について、作品一覧、開催概要を表示 | 完了 |
| F-002 | 作品一覧 | カード形式のグリッド表示（作品画像・タイトル・作家・制作年・カテゴリ） | 完了 |
| F-003 | カテゴリ絞り込み | 「すべて／絵画／写真…」のボタンで一覧を絞り込み（JavaScript） | 完了 |
| F-004 | 作品詳細ページ | 作品ごとに個別ページを生成（画像・解説・作家・技法・サイズ） | 完了 |
| F-005 | 前後ナビゲーション | 作品詳細ページで前後の作品・一覧へ移動 | 完了 |
| F-006 | 画像プレースホルダー | 画像未登録の作品はテーマカラーのグラデーションで表示 | 完了 |
| F-007 | レスポンシブ対応 | スマートフォン幅（〜720px）で 1 カラム表示 | 完了 |
| F-008 | 入力チェック | 作品データの必須項目欠落・id 重複をビルド時にエラーにする | 完了 |

### 2.2 ページ構成

| パス | 内容 |
| --- | --- |
| `index.html` | トップページ（#about / #works / #info の各セクション） |
| `works/<id>.html` | 作品詳細ページ（作品ごとに 1 ページ） |

## 3. 技術仕様

### 3.1 フォルダ構成

```
（リポジトリのルート）
├── CLAUDE.md               # Claude Code 使用規約
├── build.py                # ビルド用 CLI（--serve でローカル確認）
├── exhibition/
│   └── builder.py          # データ読み込み・HTML 生成・出力
├── content/
│   ├── site.json           # 展覧会情報
│   ├── works.json          # 作品データ
│   └── images/             # 作品画像（任意）
├── static/
│   ├── style.css           # スタイル
│   └── main.js             # カテゴリ絞り込み
├── tests/
│   └── test_builder.py     # ユニットテスト
├── notes/                  # 仕様・進捗
└── dist/                   # 生成物（Git 管理外）
```

### 3.2 データ形式

**content/site.json**

| キー | 内容 |
| --- | --- |
| `title` / `subtitle` / `lead` | 展覧会名・英題・リード文 |
| `period` / `hours` | 会期・開館時間 |
| `venue` / `address` / `admission` | 会場・所在地・入場料 |
| `about` | 展覧会紹介文（段落の配列） |
| `contact` / `footer` | 問い合わせ文・フッター表記 |

**content/works.json**（作品の配列。表示順は配列順）

| キー | 必須 | 内容 |
| --- | --- | --- |
| `id` | ○ | 英数字とハイフン。詳細ページのファイル名になる（重複不可） |
| `title` | ○ | 作品名 |
| `artist` | ○ | 作家名 |
| `year` | ○ | 制作年 |
| `category` | ○ | カテゴリ（絞り込みボタンに使用） |
| `description` | ○ | 作品解説 |
| `medium` / `size` | | 技法・素材 / サイズ |
| `color` | | プレースホルダーの色（例 `#6bb6c9`） |
| `image` | | `content/images/` 内の画像ファイル名。指定時はプレースホルダーの代わりに表示 |

### 3.3 ビルド処理

1. `site.json`・`works.json` を読み込み、必須項目と id 重複を検証
2. `dist/` を削除して再作成し、`static/` と `content/images/` をコピー
3. `index.html` と `works/<id>.html` を生成（文字列はすべて HTML エスケープ）

## 4. 非機能要件

| 項目 | 内容 |
| --- | --- |
| 依存関係 | なし（Python 標準ライブラリのみ） |
| 対応ブラウザ | 最新の Chrome / Edge / Safari / Firefox |
| セキュリティ | 出力時に HTML エスケープを行い、データ由来のスクリプト混入を防ぐ |
| アクセシビリティ | `lang="ja"`、画像の代替テキスト、プレースホルダーに `aria-label` を付与 |
